# Architecture Docs Prompt (Generate `/docs/architecture/` from `ARCHITECTURE_GUIDE.md`)

**Last Updated**: January 4, 2026

## How to use this prompt

Copy/paste **this entire file** into an LLM and provide your repo. The LLM must implement a documentation workflow where:

- You maintain an architecture narrative in markdown (e.g., `markdown-documentation/ARCHITECTURE_GUIDE.md`)
- A build script generates a static HTML version at `public/docs/architecture/index.html`
- The output is readable, linkable (heading IDs), and supports code blocks/tables

### Reference implementation (ICJIA)

- Architecture guide (long-form): [`markdown-documentation/ARCHITECTURE_GUIDE.md`](https://github.com/ICJIA/icjia-accessibility-portal/blob/main/markdown-documentation/ARCHITECTURE_GUIDE.md)
- Generator script (custom markdown→HTML): [`scripts/generate-architecture-docs.js`](https://github.com/ICJIA/icjia-accessibility-portal/blob/main/scripts/generate-architecture-docs.js)
- Output HTML: [`public/docs/architecture/index.html`](https://github.com/ICJIA/icjia-accessibility-portal/blob/main/public/docs/architecture/index.html)

---

## Instructions to the LLM (do these steps)

### 1) Create the markdown source document

Create `markdown-documentation/ARCHITECTURE_GUIDE.md` (or use your existing architecture doc) with:

- Purpose and constraints
- Directory structure
- Key architectural decisions
- How build + deploy works
- Challenges & solutions
- Links to key source files

### 2) Create the generator script

Create `scripts/generate-architecture-docs.js` that:

- Reads `markdown-documentation/ARCHITECTURE_GUIDE.md`
- Converts markdown → HTML
- Writes `public/docs/architecture/index.html`

This repo uses a **custom converter** (no markdown dependency) that handles:

- code blocks (including ASCII trees)
- tables
- headings with autogenerated IDs
- external links get `target="_blank" rel="noopener noreferrer"`

Reference:

- [`scripts/generate-architecture-docs.js`](https://github.com/ICJIA/icjia-accessibility-portal/blob/main/scripts/generate-architecture-docs.js)

### 3) Add a package.json script

Add something like:

- `"generate:docs": "node scripts/generate-architecture-docs.js"`

### 4) Ensure the docs portal links to it

Ensure your docs portal hub `public/docs/index.html` includes a card linking to:

- `/docs/architecture`

Reference:

- [`public/docs/index.html`](https://github.com/ICJIA/icjia-accessibility-portal/blob/main/public/docs/index.html)

### 5) Verify (must pass checklist)

Run:

```bash
node scripts/generate-architecture-docs.js
```

Verify:

- File exists: `public/docs/architecture/index.html`
- Headings are linkable (IDs)
- Code blocks render correctly
